# M0 — Skeleton checkpoint

**Status:** complete, 15 October 2026.

## What was built

- Strict TypeScript, Vite, Vitest, shared units, deterministic math and PRNG,
  a double-buffered shared state layout, and backend/action/event contracts.
- A fixed-tick CPU backend, tick-keyed actions, event ring buffer, simulation
  worker, and seed-dependent gravel, sand, and soil layers.
- The Paper renderer and browser preview, with its visual guide in
  [`src/render/STYLE.md`](../../src/render/STYLE.md).
- The headless jar preview, which writes daily PNGs, a contact sheet, a JSON
  report, and a SHA-256 hash of the final state buffers.
- Windows and Ubuntu CI for tests, build, the ten-day preview, deterministic
  replay checks, and contact-sheet artifacts.

## Acceptance results

- `npm ci`, `npm test` (22 tests), and `npm run build` pass on Windows.
- GitHub Actions passes on both `windows-latest` and `ubuntu-latest`.
- The seeded PRNG's checked-in 1,000-value vector is tested on both runners.
- The 10,000-tick replay is byte-identical, and a temporary `Math.random()`
  mutation changed the state hash and failed the determinism test.
- `npm run jar -- --seed 7 --days 10 --out out/ci` produced ten daily images,
  a contact sheet, and the report on Windows and CI.
- The browser preview displayed the generated jar; the same Paper renderer
  is tested against Node canvas output.

The local preview is at `out/ci/contact-sheet.png`. Download the Windows or

## Known gaps

- M0 intentionally contains no physical simulation beyond the seeded layers;
  the heat, light, water cycle, plants, and creatures are later milestones.
- `survive`, `parity`, `shots`, and `bench` remain placeholders until their
  milestones implement them.
- The jar has been checked in the development browser; broad browser/device
  compatibility and performance budgets remain future work.
